# `aion.maths` example notebooks

These notebooks demonstrate the categorized mathematics API. They use the
same public imports available to applications and require the core Aion
dependencies only.

| Notebook | Sections covered |
| --- | --- |
| `01_arithmetic_number_theory.ipynb` | Arithmetic and number theory |
| `02_linear_algebra.ipynb` | Vectors, matrices, and decompositions |
| `03_statistics_probability.ipynb` | Descriptive statistics and probability |
| `04_machine_learning.ipynb` | Activations, losses, and distances |
| `05_trigonometry_signal_processing.ipynb` | Trigonometry, FFT, and convolution |
| `06_random_utilities.ipynb` | Reproducible sampling and utility functions |

Run them from the repository root with Jupyter or open them in VS Code:

```bash
pip install -e .
jupyter lab aion/maths/examples/
```
